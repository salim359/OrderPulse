**E2E-13** = SES envelope check: after `OrderCreated`, the notification row has the correct **From** (`sender`) and **To** (`recipient`).

### 0. Deploy (if needed)
```bash
./scripts/deploy.sh
```

### 1. Resolve outputs
```bash
export BUS_NAME=$(aws cloudformation describe-stacks --stack-name notification-sys \
  --query "Stacks[0].Outputs[?OutputKey=='EventBusName'].OutputValue" --output text)
export NOTIF_TABLE=$(aws cloudformation describe-stacks --stack-name notification-sys \
  --query "Stacks[0].Outputs[?OutputKey=='NotificationsTableName'].OutputValue" --output text)
export SENDER=$(aws cloudformation describe-stacks --stack-name notification-sys \
  --query "Stacks[0].Outputs[?OutputKey=='SenderEmail'].OutputValue" --output text)

echo "SENDER=$SENDER"
```

Default sender is `orders@dailynonsensia.site`.

### 2. Publish OrderCreated with an explicit customerEmail
```bash
aws events put-events --entries "[
  {
    \"EventBusName\": \"$BUS_NAME\",
    \"Source\": \"demo.orders\",
    \"DetailType\": \"OrderCreated\",
    \"Detail\": \"{\\\"orderId\\\":\\\"ord-manual-13\\\",\\\"customerId\\\":\\\"cust-42\\\",\\\"customerEmail\\\":\\\"snoufa3@gmail.com\\\",\\\"totalAmount\\\":3,\\\"currency\\\":\\\"USD\\\"}\"
  }
]"
```
Expect: `FailedEntryCount: 0`.

### 3. Wait ~10s, then check the SES envelope fields
```bash
aws dynamodb query \
  --table-name "$NOTIF_TABLE" \
  --index-name by-order \
  --key-condition-expression "orderId = :o" \
  --expression-attribute-values '{":o":{"S":"ord-manual-13"}}' \
  | jq '.Items[0] | {
      status: .status.S,
      sender: .sender.S,
      recipient: .recipient.S,
      subject: .subject.S,
      sesMessageId: .sesMessageId.S
    }'
```

**Pass if:**
- `status` = `sent`
- `sender` = `$SENDER` (e.g. `orders@dailynonsensia.site`)
- `recipient` = `snoufa3@gmail.com` (same as `customerEmail` in the event)

### 4. Confirm in the inbox
Open the mail for `ord-manual-13`:

- From: `orders@dailynonsensia.site` (via amazonses.com)
- To: you (`snoufa3@gmail.com`)
- Subject: `Order confirmed: ord-manual-13`
